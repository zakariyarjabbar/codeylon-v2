# Asset provenance

## Supplied brand

The user supplied `Group4444.svg` and `Group33.png`. Copies are in `public/brand/`. Logo paths and gold fill are unchanged. The display SVG trims the empty viewBox only. Favicon SVG/PNG and Apple touch icon wrap the original logo paths in a navy square.

## Original artwork

The pixel landscape, website composition, cursor, repeated taper motif, icons, dividers, and speech bubble are original SVG/CSS artwork authored for this website. The concept previews use real HTML text and original layout code. None of the illustrative controls in the decorative hero artwork are actual site controls.

`public/og.png` is generated from a deterministic HTML composition in `scripts/social-image.mjs`, using the supplied logo and local fonts. It is a social-sharing image, not a claim about client work.

## Concept photographs

The three photographs were generated specifically for this project using the built-in image-generation tool. Exact prompts and source-file provenance are recorded in `public/images/provenance.json`.

| Published asset            | Depiction                             | Context                            |
| -------------------------- | ------------------------------------- | ---------------------------------- |
| `public/images/olio.webp`  | Mediterranean food still life         | Fictional restaurant concept       |
| `public/images/forma.webp` | Sandstone architecture and olive tree | Fictional architecture concept     |
| `public/images/still.webp` | Unlabelled skincare products          | Fictional product showcase concept |

Source images were 1536 × 1024 and optimised to 1200 × 800 WebP. They do not depict real Codeylon clients, offices, staff, or completed commissions. No stock-photo attribution is required for these original generated assets.
